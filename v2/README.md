# 捷運施工查驗系統 v2（支援空白範本 PDF）

本資料夾是在上一版（根目錄）之上新增功能後另存的獨立版本，**不影響根目錄現有檔案**；資料庫名稱獨立（`mrt-qms-v2`），兩版資料互不干擾。

## 新增：自主檢查表／抽查紀錄表可選填寫方式（二選一）
- **線上表單**：與上一版相同（逐項判定、拍照、停留點、手寫簽認）。
- **空白範本（PDF）**：後台上傳空白 PDF；現場下載 → 離線填寫並簽名 → 上傳簽名後 PDF 即完成。
  - 流程同第一版：**下載鎖定 → 上傳續填 → 現地手寫簽名 → 憑證加簽結案**。
  - 狀態：未開始／鎖定中／待流轉／待廠商簽名（抽查表）／待主任加簽（抽查表）／已結案；有完整辦理軌跡，每一版成果檔可下載。
  - 自主檢查表（廠商）：下載並鎖定 → 上傳並簽名（手寫簽名）→ 待流轉 → 最後上傳人憑證加簽結案；結案後可「解除結案」。
  - 抽查紀錄表（工務所同仁）：上傳並簽名時選下一關（其他局內人員續填／轉廠商簽名／免廠商簽名逕轉主任）→ 廠商上傳簽名 PDF → 工務所主任加簽結案。
  - 抽查紀錄表為 PDF 時，上傳時需選「合格／有缺失」（結案時決定是否放行後續停留點；有缺失自動建立缺失追蹤）。
  - 憑證加簽為模擬（實體自然人憑證／行動自然人憑證 TW FidO），不會真的讀卡。
  - PDF 範本無逐項判定與停留點。
- 現場作業「我的」可切換三種身分：廠商品管人員／捷運局工務所同仁／捷運局工務所主任。

# 捷運施工查驗系統 v2（支援空白範本 PDF）

本資料夾是在上一版（根目錄）之上新增功能後另存的獨立版本，**不影響根目錄現有檔案**；資料庫名稱獨立（`mrt-qms-v2`），兩版資料互不干擾。

## 新增：自主檢查表／抽查紀錄表可選填寫方式（二選一）
- **線上表單**：與上一版相同（逐項判定、拍照、停留點、手寫簽認）。
- **空白範本（PDF）**：後台上傳空白 PDF；現場下載 → 離線填寫並簽名 → 上傳簽名後 PDF 即完成。
  - 抽查紀錄表為 PDF 時，需另選「合格／有缺失」（會驗時決定是否放行後續停留點；有缺失自動建立缺失追蹤）。
  - PDF 範本無逐項判定與停留點。

## 開啟
`v2/index.html`（或 `v2/admin.html`、`v2/field.html`）。

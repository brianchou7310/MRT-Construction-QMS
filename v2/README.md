# 捷運施工查驗系統 v2（支援空白範本 PDF）

本資料夾是在上一版（根目錄）之上新增功能後另存的獨立版本，**不影響根目錄現有檔案**；資料庫名稱獨立（`mrt-qms-v2`），兩版資料互不干擾。

## 新增：自主檢查表／抽查紀錄表可選填寫方式（二選一）
- **線上表單**：與上一版相同（逐項判定、拍照、停留點、手寫簽認）。
- **空白範本（PDF）**：後台上傳空白 PDF；現場下載 → 離線填寫並簽名 → 上傳簽名後 PDF 即完成。
  - 流程同第一版：**下載鎖定 → 上傳續填 → 現地手寫簽名 → 憑證加簽結案**。
  - 狀態：未開始／鎖定中／待流轉／待廠商簽名（抽查表）／待主任加簽（抽查表）／已結案；有完整辦理軌跡，每一版成果檔可下載。
  - 自主檢查表（廠商）：下載並鎖定 → 上傳並簽名（手寫簽名）→ 待流轉 → 最後上傳人憑證加簽結案；結案後可「解除結案」。
  - 抽查紀錄表（工務所同仁）：上傳並簽名時選下一關（其他局內人員續填／轉廠商簽名／免廠商簽名逕轉主任）→ 廠商上傳簽名 PDF → 工務所主任加簽結案。
  - 抽查紀錄表為 PDF 時，上傳時需選「合格／有缺失」（結案時決定是否放行後續停留點；有缺失自動建立缺失追蹤）。
  - 憑證加簽為模擬（實體自然人憑證／行動自然人憑證 TW FidO），不會真的讀卡。
  - PDF 範本無逐項判定與停留點。
- 現場作業「我的」可切換三種身分：廠商品管人員／捷運局工務所同仁／捷運局工務所主任。

## 開啟
`v2/index.html`（或 `v2/admin.html`、`v2/field.html`）。

## 修正紀錄（資料流斷點）
1. **停留點未放行不可簽認**：送出前檢查所有 ☆停留點（判「╱ 無此項」者除外）皆已合格放行；已簽認的表單不再被會驗結果回寫。
2. **停留點判 ╳ 的改善流程**：判定缺失即建立缺失追蹤 → 改善後重新判定 ○（缺失轉「待複查」）→ 申請會驗 → 會驗合格時缺失自動結案；會驗不合格者，改善後可直接重新申請，合格時同樣自動結案。
3. **PDF 表單簽辦待辦**：今日待辦新增「表單簽辦」分頁，只列出輪到目前身分辦理的 PDF 表單（廠商：下載鎖定／加簽結案／廠商簽名；工務所：下載鎖定／續填；主任：加簽結案）。廠商不再看到抽查分頁。
4. **含停留點的自主檢查表不可設為 PDF**（後台切換與儲存時檢查）；PDF 自主檢查表上傳時須選檢查結果，判「有缺失」結案後自動建立缺失追蹤。
5. **關聯子表單連到真實紀錄**：表5-4、5-6、5-7 等依「同標案＋同單元＋表號」找紀錄，簽認／結案後主表才可判 ○；可從主表直接建立或開啟子表單，完成後返回主表自動帶入。
6. **項目永久代碼（key）**：範本項目新增 key，抽查表以 srcKey 對應自檢項目；範本改版、項次重排後會驗仍對應正確項目，「從自主檢查表同步」一律對應最新版本。舊資料開啟時自動補上 key。

## 修正紀錄（移除寫死資料）
1. **缺失歸屬標案**：依標案代號查標案資料，不再「非 CF671 一律歸 CF624H」。
2. **分項工程名稱與地點**：新建自主檢查帶入分項工程名稱，預設位置取標案「施工地點」，不再寫死「Y01站」。
3. **人員改由「帳號與權限」帶入**：
   - 現場「目前身分」對應帳號的姓名與單位，頁首顯示單位與姓名。
   - 簽認人依該標案承包商的「廠商品管人員」「工地授權代表」帶入；抽查人員為目前登入的工務所同仁。
   - 會驗申請人為申請者的單位與姓名；Email 收件人列出工務所人員帳號；逾時往上通知「捷運局工務所主任」帳號。
   - 帳號未設定時，畫面明確提示，不再顯示假名字。
4. **開始會驗**：依自主檢查表或申請單的分項工程，找該分項工程的抽查紀錄表；找不到就提示「尚未設定抽查紀錄表範本」，不再套用連續壁的表。會驗申請新增 subworkId，舊資料開啟時自動補上。
5. **連結表單**：可連結的表單改為「同分項工程、已發布的其他自主檢查表」，名稱取自範本，不再寫死表5-4～5-9。
6. **範本匯入**：
   - 新增選填欄位「表單類型」（自主檢查表／抽查紀錄表）、「表號」、「連結表號」，可以匯入抽查紀錄表。
   - 沒填表號時自動編為 IMP-1、IMP-2…。
   - 表號已存在時，要求改用「匯入為新版本」。
   - 連結表單必須填存在的表號。
   - 「匯入檢查項目」同樣支援「連結表號」。

## 修正紀錄（補齊檢核）
1. **重複建表**：同標案＋同表號＋同單元已有填寫中的表單時，直接開啟該表單；已有簽認完成的表單時提示，確認「仍要建立」才會新增（例如重新檢查）。
2. **掃描 QR**：單元有多張表時列出清單讓使用者選擇，也可以「新增此單元的其他表單」。
3. **刪除檢查**：分項工程已有範本、紀錄、會驗或缺失時不可刪除；參考文件仍被範本引用時不可刪除。
4. **缺失流程**：
   - 廠商「回報改善完成」須填改善說明並附至少 1 張照片。
   - 工務所須等廠商回報後才能複查，可選「複查合格・結案」或「退回重新改善」（須填原因）。
   - 每一步都記錄在處理歷程，後台與現場流程一致。
   - 自主檢查表勾選「已完成改善」時，缺失項目須附照片；簽認後缺失直接進入「待複查」，不需廠商再回報一次。
5. **取消會驗**：「檢驗中」可取消（須填原因），回到「已排定」，未簽認的抽查紀錄草稿作廢，之後可改期或重新開始。
6. **退回原因**：會驗申請被退回後，廠商在待辦「會驗」分頁與自主檢查表的停留點都會看到「已退回」與退回原因，可修正後重新申請。

## 修正紀錄（統計數字）
1. **抽查率**：改為「有完成抽查的自主檢查表張數 ÷ 自主檢查表總張數」。同一張表抽查多次只算一次，不會超過 100%。
2. **抽查只計已完成**：抽查張數與合格率只計「已簽認／已結案」的抽查紀錄。
3. **PDF 抽查合格率**：依上傳時選的判定結果計算，判「有缺失」不再被算成合格。
4. **總覽卡片跟著標別篩選**：自主檢查表張數也會跟著標別篩選，不再只篩抽查數。
5. **「本週排定會驗」改為「未來 7 天會驗」**：從今天 0 點起算，含待回覆、已排定、檢驗中。
6. **舊資料補對應關係**：會驗申請與抽查紀錄自動補上對應的自主檢查表，抽查率才算得出來。

## 新增：開始會驗時可選擇抽查紀錄表
工務所在會驗申請詳情（現場與後台）可以選「會驗使用的抽查紀錄表」，列出同分項工程已發布的線上與 PDF 抽查表。預設是含本停留點對應項目的線上抽查表；選 PDF 抽查表時，走「下載鎖定 → 上傳判定 → 廠商簽名 → 主任加簽結案」流程，結案合格即放行停留點。

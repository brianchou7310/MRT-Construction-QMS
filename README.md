# 捷運施工品管系統（靜態雛形）

純 HTML + Vue 3（本地 `lib/vue.global.prod.js`）+ JavaScript + IndexedDB，無需建置、無後端。

| 檔案 | 說明 |
|---|---|
| `index.html` | 入口 |
| `admin.html` | 後台管理（桌機）：品管總覽、停留點會驗、自主檢查／抽查／缺失、標案與分項、表單範本（版本控制）、CSV 匯入、參考文件、帳號、參數 |
| `field.html` | 現場作業（RWD，平板雙欄／手機單欄）：待辦、自主檢查、停留點申請、抽查紀錄、手寫簽認 |
| `js/db.js` | IndexedDB 封裝、示範資料、業務規則（停留點鎖定、24h/8h、版本、簽認雜湊） |

## 執行
直接用瀏覽器開啟 `index.html`，或 `npx http-server .`。兩頁共用同一個 IndexedDB（同源），可同時開啟互相同步。
「還原示範資料」可重設。現場頁於「我的」切換身分（廠商／監造）。
